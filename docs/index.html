Why NexStatus

One glance

Stop opening five apps to check whether Claude, Codex, Go, or Grok is about to rate-limit you.

Fully customizable glass

Chart style, five themes, four glass recipes, plus live opacity / blur / saturate — your MenuBar, your frost.

Privacy first

Tokens stay local for probes. Snapshots never store API keys. Secrets stay off the repo.

Install

git clone https://github.com/awe7893625/NexStatus.git
cd NexStatus
./scripts/install.sh

Needs macOS + Hammerspoon + Python 3. Optional: Claude Code, Codex, OpenCode Go, Grok CLI for each usage source.

Security review

✓
No API keys in git — collector only reads existing local auth files or env vars at runtime.
✓
No secrets in snapshot — ~/.cache/nexstatus/status.json holds percentages, not tokens.
✓
Personal workspace URLs redacted — OpenCode error messages strip private workspace paths.
✓
Obsidian vault stays private — team vault repo is separate and private; not part of NexStatus.
✓
MIT license — free to use, fork, and contribute.

What NexStatus never does

• Upload your chats or vault notes

• Commit auth.json or env files

• Expose Tailscale / home paths in public docs

• Require a cloud account for the MenuBar itself
